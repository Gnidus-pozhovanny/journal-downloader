# Journal Downloader

Клиент для скачивания заданий из электронного журнала TOP Academy. Поддерживает Windows x64 и Linux x86-64.

Готовые сборки и комплект для Codex доступны в [релизах](https://github.com/Gnidus-pozhovanny/journal-downloader/releases). Для установки навыка см. [инструкцию](JournalDownloader/skills/INSTALL.md).

Исходники клиента находятся в `JournalDownloader/scripts/`.
